# 빽코트 Google Play 출시 체크리스트

## 기본 정보

- 앱 이름: 빽코트 - 농구 코트 찾기
- 패키지 이름: `kr.backcourt.backcourt`
- 카테고리: 스포츠
- 광고 포함: 아니요
- 개인정보 처리방침: https://backcourt.kro.kr/privacy/
- 계정 삭제: https://backcourt.kro.kr/delete-account/
- 문의 이메일: backcourtkr@gmail.com

## 업로드

1. `./tool/build_android_release.sh`로 AAB를 생성합니다.
2. `build/app/outputs/bundle/release/app-release.aab`를 내부 테스트 트랙에 먼저 올립니다.
3. Play 앱 서명을 사용 설정하고 `android/upload_certificate.pem`을 업로드 인증서로 보관합니다.

## 앱 액세스

로그인이 필요한 앱으로 표시합니다. 심사자가 핵심 기능을 확인할 수 있도록 별도의 이메일 테스트 계정과 로그인 방법을 등록합니다.

## 대상 연령

어린이 대상 앱으로 설계되지 않았으므로 13세 이상을 선택합니다. 미성년자 이용에는 보호자 동의가 필요하다는 정책을 적용합니다.

## 데이터 보안 작성 기준

실제 앱 동작을 기준으로 다음 항목을 신고합니다.

- 위치: 주변 코트 검색과 현장 GPS 체크인
- 개인정보: 이메일·전화번호·소셜 로그인 식별자, 이름, 사용자 아이디, 프로필
- 사진 및 동영상: 프로필, 게시물, 리뷰에 사용자가 선택하여 업로드
- 앱 활동: 체크인, 플레이 기록, 리뷰, 게시물, 댓글, 좋아요·즐겨찾기·차단·신고
- 기기 또는 기타 식별자: 푸시 알림용 기기 토큰
- 데이터 처리 목적: 앱 기능, 계정 관리, 알림, 안전·부정 이용 방지
- 전송 중 암호화: 예
- 삭제 요청 제공: 예 (앱 내 계정 탈퇴 및 공개 웹페이지)
- 데이터 판매: 아니요

Google Firebase와 Cloudinary 등 사용 중인 SDK가 수집하는 데이터도 Play Console의 최신 안내와 SDK 문서를 대조한 뒤 최종 제출합니다.

## 출시 전 콘솔 작업

- 콘텐츠 등급 설문 완료
- 데이터 보안 양식 완료
- 앱 액세스용 심사 계정 입력
- 스토어 등록정보와 스크린샷 등록
- 최신 개인 개발자 계정이면 비공개 테스트 참여자 12명을 14일 연속 유지
- 테스트 후 프로덕션 액세스 신청
