계정 및 데이터 삭제

빽코트 계정 또는 일부 데이터 삭제 안내

계정 전체를 삭제하거나, 계정은 유지하면서 작성한 콘텐츠만 삭제할 수 있습니다. 앱을 이용할 수 없는 경우에는 이메일로 요청해 주세요.

앱에서 직접 삭제

MY → 설정 → 계정 탈퇴

본인 확인 후 계정과 연결된 프로필, 게시물, 댓글, 리뷰, 출석·플레이 기록, 즐겨찾기와 알림 정보가 삭제됩니다.

계정을 유지하고 일부 데이터 삭제

피드에서 본인 게시물의 메뉴를 열어 게시물 삭제를 선택하거나, 게시물 상세 화면에서 본인 댓글을 삭제할 수 있습니다. 게시물을 삭제하면 해당 게시물에 첨부한 사진과 동영상도 함께 삭제됩니다.

앱에서 직접 삭제하기 어려운 데이터는 아래 이메일 요청을 통해 삭제할 수 있습니다. 삭제할 데이터 유형을 구체적으로 적어 주세요.

이메일로 요청

앱을 다시 설치하지 않아도 요청할 수 있습니다. 본인 확인을 위해 빽코트 사용자 아이디, 가입에 사용한 로그인 방법, 계정 전체 또는 삭제할 데이터 유형을 적어 주세요. 비밀번호는 보내지 마세요.

삭제 요청하기

삭제되는 데이터와 보관 기간

계정 전체 삭제: 인증 계정, 프로필, 게시물과 첨부 미디어, 댓글, 리뷰, 출석·플레이 기록, 즐겨찾기, 알림과 기기 토큰을 삭제합니다.

일부 데이터 삭제: 요청에서 지정한 게시물, 첨부 미디어, 댓글 등 해당 데이터만 삭제하고 계정과 나머지 데이터는 유지합니다.

추가 보관: 삭제 요청 처리 기록과 부정 이용·분쟁 대응에 필요한 최소 정보는 요청 완료 후 최대 90일간 분리 보관한 뒤 삭제합니다. 관련 법령이 더 긴 보관 기간을 요구하는 경우에는 해당 법정 기간 동안만 보관한 뒤 삭제합니다.
